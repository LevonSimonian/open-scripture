# Where this text comes from

**Scripture text** — Catholic Public Domain Version (CPDV), a modern English translation
made from the Latin Vulgate and released into the public domain. It contains all 73 books
of the Catholic canon. No permission or licence fee is required to publish it.

**Cross-references** — derived from the Treasury of Scripture Knowledge, a public domain
19th-century reference work, via the openbible.info dataset (CC BY). These cover the 66
books shared across traditions; the seven deuterocanonical books have none, which the
study panel says plainly rather than showing an empty list.

**Why not a modern Catholic translation?** The NABRE, NRSV-CE and Jerusalem Bible are all
in copyright and cannot be bundled into a free site. CPDV is the best public domain option
that carries the full 73-book canon.

Files are one JSON per book, loaded only when a reader opens that book, so no one downloads
9MB to read a psalm.
